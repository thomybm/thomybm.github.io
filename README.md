# Thomas Bustos Millon, portfolio

A static site: plain HTML, CSS and a few lines of JavaScript. No build step.

## Publish on GitHub Pages

1. Create a new public repository named `thomybm.github.io`.
2. Upload everything in this folder (keep the `assets` folder as it is).
3. In the repository, open Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://thomybm.github.io/`.

## Edit

- Page text lives in the six `.html` files.
- Colours, fonts and layout live in `assets/site.css`. The colour tokens are at the top.
- Images live in `assets/img`.

Every figure on the site names its source. If a number changes, change the source beside it too.
